# 主管機關資料集

金管會銀行局的公開月報。`src/regulatorDatasets/disclosures.py` **刻意完全獨立**，不 import 其他三個套件，這樣它能單獨測試與排程。

> 可信度：**程式碼 > 緊鄰常數的註解 > 這份文件**。

## 兩個資料集

| 資料集 | 來源表 | 單位 |

| 逾期放款總額（含逾放比率、備抵呆帳/逾期放款） | 本國銀行資產品質評估分析統計表 | 新臺幣百萬元 |

## 頁面慣例（2026-07 對真實下載確認）

- 兩個頁面都是純伺服器渲染的 HTML——每個月的連結已經在原始碼裡，不需要 JavaScript 渲染。
- 兩個網站用**不同的檔名慣例**，所以各自有自己的期別擷取正規表達式，而不是共用一個猜測：
  - NPL：`...統計表115_05(2).xlsx` → 民國 115 年 5 月（`(N)` 後綴是不固定的修訂重傳）
  - 信用卡：`.../11412_信用卡重要資訊揭露.zip` → 民國 114 年 12 月（YYYMM 連寫，而且試算表包在 ZIP 裡，旁邊還有一個 .ods 雙胞胎——頁面標成 "excel&ods"）
- 兩邊的「最新」都是解析每個連結的 (年, 月) 取最大值，**從不**用命名公式去組 URL。
- `_list_period_links` 的 `ext` 參數先把 href 掃描收窄到一種副檔名，這樣 NPL 頁面的 PDF 雙胞胎（同一期、錯的格式）搶不到 dict 的位置。
- 兩份試算表都是一張平坦的工作表：一列標題，然後一家銀行一列。

## 為什麼不能停用 SSL 驗證

`_fetch_url` 用系統預設的（會驗證的）SSL context。

在某些環境會丟 `SSLCertVerificationError`——那代表**你這台機器的 CA 信任存放區缺了一張中介憑證**（某些 Windows Python 安裝常見，測試這個模組時重現過），不代表這個連線該降級成不驗證。修法是 `pip install pip-system-certs`（用 Windows 存放區）或 certifi。

**停用驗證會重新打開 MITM 攻擊面。** 這是 AGENTS.md 的紅線第一條。

程式碼要自己把這個訊息丟成 `RuntimeError`，因為 `urlopen` 會把 SSL 錯誤包在 `urllib.error.URLError` 裡而不是 `ssl.SSLError`——只 catch `ssl.SSLError` 的呼叫端會漏掉（測試確認）。

CI 與 A/B 都**不可以真的連上 `banking.gov.tw`**，必須 stub `_fetch_url`（紅線第二條）。真的連上外網視為 harness 設定失敗，不以重跑判定結果。

## 逾放比率曾經取錯表

逾放比率與備抵呆帳（逾期放款覆蓋率）跟逾期放款總額住在**同一張**「本國銀行資產品質評估分析統計表」——真實下載確認：這兩個是**全行**比率（所有放款，不是信用卡專屬），所以它們屬於 `fetch_overdue_loans`，不是信用卡那張表。

早期版本從**信用卡**表取了兩個名字相近的欄位（逾期三個月以上帳款比率／備抵呆帳提足率）。那是真實存在、但不同的、信用卡專屬的指標，跟這張表的全行數字對不上：114年12月的中信，全行是 0.13%／950.93%，信用卡表是 0.12%／299.62%。依使用者從實際政府頁面提供的 ground truth 修正。

兩者在試算表裡**已經是百分比尺度的數字**——不要再乘除，顯示時只加上 `%`。

## 欄位靠標題文字定位

欄位位置是靠**標題文字**找的，不是固定索引，這樣將來欄位重排不會靜默回傳錯的指標。

比對是整段去空白後**完全相等**，不是子字串——一個指標的名字可能是另一個的子字串。

兩趟：

1. 前 `max_scan_rows` 列裡任何一個單格完全等於目標（常見情況：`銀行別`、`循環信用餘額`）。
2. 沒命中才試 **3 列堆疊**標題：有些真實表把一個指標名拆在同一欄連續三列（真實下載確認：NPL 表的 `逾放`／`比率`／`(%)` 要接起來才讀成 `逾放比率(%)`）。

堆疊標題帶的起點定位成「**至少兩欄同時有字串**的第一列」——這才能跟它上面那些只填第一欄的標題／日期／單位前言行區分開。從第 1 列開始盲目串接，會把那些前言行拉進第一欄自己的「標題」，結果什麼都對不上。只串接那三列的帶，絕不往下伸進資料列。

## 數字有時是文字

兩份試算表都以 `data_only=True` 讀，但信用卡那份把數字存成**文字**，NPL 那份存成真正的數字——所以兩種都接受，不假設。

## 要求的月份還沒公布時

`resolve_period`：沒指定期別就取最新；有指定但沒公布，退回**不晚於**要求的最新月份（絕不取更晚的——未來月份的數字不能拿來代替你問的那一季），並回報 `exact=False` 讓呼叫端說出實際用了哪一期。

這些資料集會落後一到兩個月，所以問一個剛結束的季度常態性地會走到這條路徑，而不是錯誤。

有一種情況無法遵守「絕不更晚」：要求的月份**比公布的全部都舊**。那時沒有任何東西在它之前，於是回傳最舊的可用月份——那**確實**晚於所要求的。`exact=False` 與呼叫端的 note 都會揭露這件事；docstring 曾經直接與此矛盾。

note 的措辭按方向分：比整個資料集還舊的要求是往**前**退到最舊月，把那說成「那個月還沒公布」根本是錯的。

## 快取

`download_file` 依 URL 自己的檔名快取到 `npl_cache/`，同一個月內重跑不會重抓。來源用同一個檔名重傳修訂版時，刪掉快取檔強制更新。

`npl_cache/` 在 repo 根目錄，也就是 `src/regulatorDatasets/` 往上**三層**，不是兩層——這個模組往下搬過一層目錄，同一個運算式曾靜默指向 `src/`。`core/industry.py` 被同一件事咬過。
